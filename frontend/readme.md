## 📁 Structure

```
streamlit_app/
├── streamlit_app.py          ← Main app (entry point)
├── utils/api_client.py       ← Backend integration
├── components/               ← UI components (expandable)
├── .streamlit/config.toml   ← Dark theme
├── requirements.txt
├── Dockerfile
└── test_ui.py
```

## 🚀 Run Locally

```bash
cd streamlit_app
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Open → `http://localhost:8501`

## ☁️ Deploy

**Streamlit Cloud** → connect GitHub → select `streamlit_app/streamlit_app.py`  
**Render** → see `DEPLOYMENT.md`
